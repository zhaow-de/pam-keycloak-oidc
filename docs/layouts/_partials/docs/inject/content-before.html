{{/* Unreleased-version banner. Shown on every page of a build whose current version is flagged `prerelease` in the versions list. The flag lives beside the version's own entry in hugo.toml rather than in a second parameter, so the label, the URL and the prerelease status cannot drift apart. The colours are inline and alpha-blended because the theme styles only a generic `book-hint` and provides no variant for a warning; an alpha background over the page's own colour reads correctly in both the light and the dark theme. */}} {{ $current := site.Params.versionCurrent }} {{ $isPrerelease := false }} {{ $stableURL := "" }} {{ $stableLabel := "" }} {{ range site.Params.versions }} {{ if eq .label $current }} {{ $isPrerelease = .prerelease }} {{ end }} {{ if not .prerelease }} {{ $stableURL = .url }} {{ $stableLabel = .label }} {{ end }} {{ end }} {{ if $isPrerelease }}
This documents {{ $current }}, which is not released yet. Anything here may change before release, and the downloads it points at are prereleases — do not deploy them to a machine you need. {{ with $stableURL }} The current stable documentation is {{ $stableLabel }}. {{ end }}
{{ end }}
